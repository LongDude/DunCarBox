# Схема укладки

`PackingViewer` принимает `box`, серверный `step`, `showAll` и snapshot `products`.
React Three Fiber/Three.js загружаются лениво родительским экраном результата.

Источники: `docs/CONTRACTS.md` и `docs/UX.md`. Типы брать из `src/types/packing.ts`.
Отображение координат: `(x,y,z) → (x,z,-y)`; `Placement.position` — минимальный угол.
Центр mesh: `(x + length/2, z + height/2, -(y + width/2))`.
Размеры mesh: `(length, height, width)` из ориентированных `Placement.dimensions`.
Не применять ориентацию повторно: `dimensions` уже учитывает поворот.

Все преобразования находятся в `geometry.ts`; нормализация `6 / max(L,W,H)`
применяется только при рендеринге. Коробка и товары используют один origin и scale.
Товары отрисовываются одним `InstancedMesh` с общей геометрией. Камера помещает
ограничивающую сферу коробки в меньший угол обзора и пересчитывается при resize;
OrbitControls позволяют вращать/приближать сцену, кнопка сбрасывает вид.
Постоянный цикл анимации не используется: `frameloop="demand"`.

`visiblePlacements` показывает step <= k; подготовка пуста, закрытие показывает все.
`showAll` явно включает обзор всей укладки. Текущий экземпляр получает двойной
контур и текстовую подпись. Цвет зависит только от product_id. Легенда и нажатие
на товар позволяют осмотреть экземпляр, не меняя шаг инструкции.

Режим «По слоям» группирует одинаковые `position.z`, без произвольных срезов.
Вид сверху сохраняет реальный масштаб; передняя сторона находится снизу.
При переходе шага автоматически выбирается слой текущего товара. Клавиатурный
доступ реализован через легенду и SVG-товары (Enter/Space). Отсутствие WebGL2,
ошибка создания Canvas и потеря контекста переключают на этот же вид.

`geometry.test.ts` проверяет оси, центр, отсутствие повторного поворота, общий
масштаб и границы, framing разных пропорций, шаги, слои и стабильность цветов.
