# Статус хакатонного MVP

## Завершено

- [x] Foundation: monorepo, модели, API v1, единицы/координаты/ориентации.
- [x] PostgreSQL-only CRUD, seed, конфигурация и Docker.
- [x] Реальный детерминированный packing engine и независимый валидатор.
- [x] Геометрия, повороты, опора, вес, остатки, причины, метрики и альтернативы.
- [x] Формы заказа и каталога, пошаговый 3D/слои, JSON и печать/PDF.
- [x] Подключение engine к default API без изменения DTO.
- [x] Инструкции согласованы с placements главного плана и альтернатив.
- [x] Четыре реальные demo-сценария, изменённый заказ и негативные случаи.
- [x] 322 backend-теста, 71 frontend-тест, 19 браузерных сценариев.
- [x] Production build и полный Docker Compose; три сервиса healthy.
- [x] Сохранение PostgreSQL-каталога и отсутствие повторного seed после restart.
- [x] Code review, README, CONTRACTS и AGENT_HANDOFF.

## Возможное развитие после MVP

- [ ] Детерминированный бюджет поиска / асинхронные задания для больших заказов.
- [ ] Механические ограничения, хрупкость, нагрузки и зазоры по отдельному контракту.
- [ ] Сохранение истории, резервирование остатков и авторизация.
- [ ] Дополнительная оптимизация загрузки Three.js.

Эти пункты не входят в обязательный scope текущего хакатонного MVP.
